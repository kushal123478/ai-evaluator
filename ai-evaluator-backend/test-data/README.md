# Test Data Directory

This directory contains test case files for the AI Output Evaluator.

## File Structure
- `*.json` - AI extracted data for validation
- `*.pdf` - Corresponding PDF documents
- Each JSON file should have a matching PDF with the same base name

## Test Cases
- invoice_001 through invoice_011 - Various invoice types
- receipt_002 - Coffee shop receipt
- bank_statement_003 - Bank statement sample
